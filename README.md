# toto予想サイト（クラウド版・自分専用）

PC に Python は不要。GitHub が自動でデータ取得・予想・サイト更新を行い、
スマホのブラウザからパスワードで開きます。

- 更新: 毎時（金土日の 9〜21時は20分ごと）＋ 手動実行
- 予想データは暗号化して公開（パスワードを知らない人には読めない）

## ファイル
- engine.py        データ取得・モデル・分析
- updater.py       取得〜学習のまとめ
- build_site.py    サイト生成（暗号化）
- web/index.html   スマホ画面（買い目は画面上で予算に合わせて再計算）
- .github/workflows/update.yml  自動実行の設定
